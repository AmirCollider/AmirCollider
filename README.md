### 👋 About me

I'm **AmirCollider** — an indie developer building games *and* the infrastructure that runs behind them. My work spans the whole stack: **Unity / Android** game clients, **serverless edge backends** on Cloudflare Workers, and **trilingual, accessible web interfaces** with light/dark theming and correct RTL/LTR layout.

I care about clean architecture, security by default, and the polish nobody notices until it's missing.

### 🚀 This repository — the AmirCollider platform

Everything at **[amircollider.com](https://amircollider.com/)** runs from this repo: one Cloudflare Worker, no origin server, no build step, no client framework.

| | Feature | What you get |
|:---:|---|---|
| 🔐 | **Google sign-in, everywhere** | One OAuth flow that works for web, desktop loopback *and* Android deep links |
| 👤 | **Player accounts** | Profile, avatar, username rules, cloud saves — playable on a phone, editable in a browser |
| 🏆 | **Leaderboards** | Public score tables, with banned players filtered out automatically |
| 🛡️ | **Real moderation** | Bans and time-boxed restrictions that actually block score submissions |
| 🛒 | **In-game storefront** | Catalogue, crypto checkout, entitlements — buy in the browser, own it in the game seconds later |
| 🔑 | **Licence server** | Keys, activations, seat limits and offline tokens for the paid Unity extension |
| 📧 | **Delivery that doesn't drop** | A cron safety net retries every unsent key and resumes every paid-but-undelivered order |
| 🎛️ | **Two operator panels** | `/thegod` runs the games, `/testsite` rehearses the whole checkout without money moving |
| 🌍 | **Three languages, always** | Every page in fa / en / ja with correct RTL–LTR — not a translation layer, a design constraint |
| 🌗 | **Light / dark / auto** | Theme resolved before first paint, so there is never a wrong-colour flash |
| 📊 | **Live status** | Health checks, ping tests, metrics and release notes, built in |

### 👋 自己紹介

**AmirCollider** です。ゲームと、その裏側で動くインフラの両方を作るインディー開発者です。**Unity / Android** のゲームクライアントから、Cloudflare Workers 上の**サーバーレス・エッジバックエンド**、ライト/ダークテーマと正しい RTL/LTR レイアウトを備えた**多言語・アクセシブルな Web インターフェース**まで、スタック全体を手がけています。

クリーンなアーキテクチャ、デフォルトでのセキュリティ、そして無くなって初めて気づくような細部を大切にしています。

### 🚀 このリポジトリ — AmirCollider プラットフォーム

**[amircollider.com](https://amircollider.com/)** のすべてがこのリポジトリから動いています。Cloudflare Worker が 1 つだけ。オリジンサーバーなし、ビルド工程なし、クライアントフレームワークなし。

| | 機能 | 何ができるか |
|:---:|---|---|
| 🔐 | **どこでも Google サインイン** | Web・デスクトップ・Android ディープリンクに対応した 1 つの OAuth フロー |
| 👤 | **プレイヤーアカウント** | プロフィール、アバター、ユーザー名規則、クラウドセーブ |
| 🏆 | **ランキング** | 公開スコア表。BAN されたプレイヤーは自動で除外されます |
| 🛡️ | **実効性のあるモデレーション** | BAN と期間制限が、実際にスコア送信をブロックします |
| 🛒 | **ゲーム内ストア** | カタログ、暗号資産決済、エンタイトルメント。ブラウザーで購入し、数秒後にはゲーム内で所有 |
| 🔑 | **ライセンスサーバー** | 有料 Unity 拡張のキー、アクティベーション、シート上限、オフライントークン |
| 📧 | **取りこぼさない配信** | cron が未送信のキーを再試行し、支払い済み未配信の注文を再開します |
| 🎛️ | **2 つの管理パネル** | `/thegod` でゲームを運用し、`/testsite` で決済フロー全体をお金を動かさずリハーサル |
| 🌍 | **常に 3 言語** | 全ページがペルシャ語・英語・日本語。翻訳レイヤーではなく設計上の制約です |
| 🌗 | **ライト / ダーク / 自動** | 初回描画前にテーマを決定するため、色のちらつきがありません |
| 📊 | **ライブステータス** | ヘルスチェック、Ping テスト、メトリクス、リリースノートを内蔵 |

### 🚀 Run it

```bash
npm install -g wrangler
wrangler dev      # 👉 http://localhost:8787
wrangler deploy   # 🌍 live
```

Bindings are in [`wrangler.jsonc`](wrangler.jsonc) — two D1 databases and one R2 bucket:

```bash
wrangler d1 execute amircollider-licenses --remote --file=migrations/0001_licenses.sql
wrangler d1 execute neon-katana-db        --remote --file=migrations/neon-katana.sql
```

Secrets go in with `wrangler secret put`. Three are **required** — the Worker refuses to start without them:

| Secret | Why it has no fallback |
|---|---|
| `*_GOOGLE_CLIENT_ID_WEB` · `*_GOOGLE_CLIENT_SECRET` | Any game that claims the `login` capability |
| `STATE_SIGNING_SECRET` | Signs OAuth state and player session cookies. It used to fall back to the Google client secret, which made one credential do two jobs — rotating it for either reason broke the other |

Everything else **degrades instead of crashing**: no payment key disables the checkout, no mail key disables delivery, and every page keeps working. 🛟

### ➕ Adding a game

One entry in `GAME_REGISTRY` in [`Config.js`](Config.js), a D1 binding, and the schema — and the `/thegod` panel generates all three for you. 🪄 Everything an operator changes afterwards (name, logo, description, download switch, prices) is a database override, so no deploy is needed for it.

📖 Full walkthrough: [`Docs/Games.md`](Docs/Games.md)
